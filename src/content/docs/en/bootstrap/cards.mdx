A card is a self-contained block about one subject, such as a course, a person or a summary. Cards sit in a grid and let the eye jump from one to the next.

## When to use it

<div class="ds-do-dont">
<Rule kind="do" title="Use it">

- One subject and one main action per card.
- The same structure in every card of a group, so they can be compared.
- A header or footer only for metadata (status, date), not for the title.

</Rule>
<Rule kind="dont" title="Don't">

- Put a card inside a card.
- Use a card for a long text or a form; use the page.
- Make the whole card a link and also put links inside it.

</Rule>
</div>

## Anatomy

A box (`card`) with an optional **image** (`card-img-top`), **header**, **body** (`card-body`: `card-title`, `card-text`, actions), **list** and **footer**.

## Classes

| Class | What it does |
|---|---|
| `card` | The box |
| `card-body`, `card-title`, `card-text` | Content |
| `card-header`, `card-footer` | Metadata above and below |
| `card-img-top` | Image at the top |
| `card-link` | Links in a row |
| `row g-0`, `col-md-*` | Horizontal layout |

## Accessibility

- The title is a real heading of the right level.
- If the whole card is clickable, there is one link that covers it, not nested links.
- Images have alternative text or are marked decorative.
