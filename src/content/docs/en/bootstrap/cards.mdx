A card is a self-contained block about one subject, such as a course, a person or a summary. Cards sit in a grid and let the eye jump from one to the next.

## When to use it

<div class="ds-do-dont">
<Rule kind="do" title="Use it">

- One subject and one main action per card.
- The same structure in every card of a group, so they can be compared.
- A header or footer only for metadata (status, date), not for the title.

</Rule>
<Rule kind="dont" title="Don't">

- Put a card inside a card.
- Use a card for a long text or a form; use the page.
- Make the whole card a link and also put links inside it.

</Rule>
</div>

## Anatomy

A box (`card`) with an optional **image** (`card-img-top`), **header**, **body** (`card-body`: `card-title`, `card-text`, actions), **list** and **footer**.

## Combinations

| Combination | Use it for |
|---|---|
| Image × body × action | The classic card: image on top, title, two lines of text and one main action. |
| Icon tile × title × text | A feature or an entry point; no image needed. |
| Figure × trend | A number, what it counts and how it moves; the trend in success or danger colour. |
| Card + badges + progress | A course or a task: status as soft badges, progress as a bar, actions in the footer. |
| Card × link | The whole card is a link (`card-hover`), with no other links inside it. |
| Card + list | A card with a flush list group for a summary or a short list. |

## What Didactika changes and why

| What we changed | Why it helps |
|---|---|
| A hairline border and a very soft shadow | The card separates from the page without the heavy outline that makes a page of cards look like a form. |
| A larger radius and more padding | It reads as a surface you can put things on; content never touches the edge. |
| The header and footer have no fill | They are metadata, so they do not compete with the title in the body. |
| Cards that are links lift and show one ring around the whole card | The user knows the whole card is the target and sees where the keyboard is. |
| Icons sit in a tile | The same piece is used in alerts, toasts, dialogs and cards, so an icon always means the same kind of thing. |

## Classes

| Class | What it does |
|---|---|
| `card` | The box |
| `card-body`, `card-title`, `card-text` | Content |
| `card-header`, `card-footer` | Metadata above and below |
| `card-img-top` | Image at the top |
| `card-link` | Links in a row |
| `row g-0`, `col-md-*` | Horizontal layout |
| `card-hover` | A card that is a link: it lifts on hover and shows the focus ring (Didactika) |
| `card-flat` | A card without a shadow (Didactika) |
| `dd-tile`, `dd-tile-lg`, `dd-tile-round` | The icon tile, in other sizes and shapes (Didactika) |
| `dd-stat`, `dd-stat-value`, `dd-stat-label`, `dd-stat-trend` | A figure with its label and trend (Didactika) |

## Accessibility

- The title is a real heading of the right level.
- If the whole card is clickable, there is one link that covers it, not nested links.
- Images have alternative text or are marked decorative.
