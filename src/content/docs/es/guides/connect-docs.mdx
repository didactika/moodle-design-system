La documentación de un plugin no debería copiar qué es un botón, una tabla o un color: debería apuntar aquí. Todo lo que sabe este sitio se publica como JSON estático, servido por GitHub Pages con cabeceras CORS abiertas, así que cualquier otra documentación, script de compilación o editor puede leerlo.

## El punto de entrada

```http
GET https://didactika.github.io/moodle-design-system/api/index.json
```

Lista las versiones de Moodle (con los enlaces a su hoja de estilos y a sus tokens), cada página con su identificador, grupo, versiones a las que aplica, título, resumen y dirección en los dos idiomas, y los demás recursos.

| Dirección | Qué contiene |
|---|---|
| `/api/index.json` | Versiones, páginas, recursos y cómo funcionan los enlaces con estado |
| `/api/pages/<id>.json` | Una página en los dos idiomas, con el texto fuente y los ejemplos que usa |
| `/api/components/index.json` | Los componentes que tienen ejemplos |
| `/api/components/<componente>.json` | El marcado de cada ejemplo de un componente, para Bootstrap 5 y para Bootstrap 4 |
| `/api/tokens/<version>.json` | Las variables CSS de esa versión de Moodle, en claro y en oscuro |
| `/api/icons.json` | Cada identificador de icono de Moodle y el nombre de Font Awesome con el que lo dibuja cada versión |
| `/api/brand.json` | Los colores, el logo y el icono de Didactika |

## Componentes

Cada ejemplo de un componente se publica como marcado que se puede usar tal cual. Viene en dos formas para cada generación de Bootstrap (Moodle 5.x usa Bootstrap 5, Moodle 4.x usa Bootstrap 4): HTML plano, y una plantilla de Moodle en la que cada icono es la llamada que hace una plantilla (`{{#pix}}t/add, core{{/pix}}`). Los identificadores de icono usados se listan aparte.

```js
const root = 'https://didactika.github.io/moodle-design-system';
const buttons = await (await fetch(root + '/api/components/buttons.json')).json();

const example = buttons.examples.find((e) => e.id === 'buttons/icons');
console.log(example.title.es);
console.log(example.bootstrap5.mustache); // para una plantilla de un plugin en Moodle 5.x
console.log(example.bootstrap4.mustache); // lo mismo, con los nombres de clase de Bootstrap 4
console.log(example.icons);               // ['t/add', 'i/import', 't/delete', ...]
```

## Estable a propósito

Cada fichero lleva `"schema": 1`. El número cambia solo cuando se quita un campo o cambia su significado; añadir campos nunca lo cambia. Un lector que compruebe el número sigue funcionando cuando el sitio crece. Los identificadores de página y de ejemplo (como `bootstrap/buttons` o `buttons/icons`) no cambian una vez publicados.

## Enlazar una página con un estado

Cualquier página se abre en un estado concreto con parámetros de la dirección, para que la documentación de un plugin pueda mostrar su pantalla como la vería un sitio.

| Parámetro | Valores | Efecto |
|---|---|---|
| `version` | `v53`, `v45`, `v41` | La versión de Moodle con la que se dibujan los ejemplos |
| `mode` | `light`, `dark` | El modo de color (el oscuro solo existe desde Moodle 5.x) |
| `brand` | `1`, `0` | La paleta de Didactika en cada ejemplo |

```
https://didactika.github.io/moodle-design-system/es/bootstrap/buttons/?version=v45&mode=light&brand=1
```

## Leer las páginas desde una compilación

```js
const index = await (await fetch(root + '/api/index.json')).json();
if (index.schema !== 1) { throw new Error('Esquema desconocido'); }

const page = index.pages.find((p) => p.id === 'bootstrap/buttons');
console.log(page.title.es, page.url.es, page.examples);

// El texto fuente de una página, para incluirlo o citarlo.
const detail = await (await fetch(page.api)).json();
console.log(detail.body.es);
```
