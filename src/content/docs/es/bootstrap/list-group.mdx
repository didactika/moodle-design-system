Un grupo de lista presenta una serie de elementos relacionados uno bajo otro: un menú, las unidades de un curso, los resultados de una búsqueda. Los elementos pueden ser enlaces o botones.

## Cuándo usarlo

<div class="ds-do-dont">
<Rule kind="do" title="Úsalo">

- Usar `list-group-item-action` cuando los elementos son enlaces o botones.
- Marcar el elemento actual como activo.
- Poner una insignia a la derecha para un recuento o un estado.

</Rule>
<Rule kind="dont" title="No">

- Usarlo para una tabla con varias columnas; usa una tabla.
- Hacer clicables unos elementos y otros no en la misma lista.
- Colorear elementos por significado sin un texto que también lo diga.

</Rule>
</div>

## Anatomía

Un contenedor (`list-group`) de **elementos** (`list-group-item`), cada uno simple, una **acción** (enlace o botón) o **contextual** (éxito, aviso…). Uno puede estar **activo** y algunos **desactivados**.

## Clases

| Clase | Qué hace |
|---|---|
| `list-group`, `list-group-item` | La lista y sus elementos |
| `list-group-item-action` | Elemento clicable con hover y foco |
| `active`, `disabled` | Estado de un elemento |
| `list-group-flush` | Sin borde exterior ni radio (dentro de una tarjeta) |
| `list-group-item-success`… | Color contextual |

## Accesibilidad

- Usa `aria-current="true"` en el elemento activo.
- Un elemento clicable es un `a` o un `button`, no un `div`.
- Un elemento desactivado lleva `aria-disabled="true"` y `tabindex="-1"`.
