A plugin never writes a Font Awesome class. It asks Moodle for an icon by its id (`t/edit`, `i/reload`), with `{{#pix}}t/edit, core{{/pix}}` in a template or `$OUTPUT->pix_icon('t/edit', ...)` in PHP, and React code uses the same ids. Moodle maps each id to an icon of its Font Awesome, and a theme can map it to another.

<Only of="v41" inline>This version draws icons with Font Awesome 4.7.</Only><Only of="v45,v53" inline>This version draws icons with Font Awesome 6.</Only>

## One meaning per icon

| Meaning | Icon | Moodle id | Use |
|---|---|---|---|
| Edit, or open an item that can still change | <span class="ds-icon-cell ds-v-scope"><i data-pix="t/edit" /></span> | `t/edit` | Profiles, migrations in review |
| Open the details of an item that cannot change any more | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/info" /></span> | `i/info` | Completed migrations |
| Show or hide, enable or disable | <span class="ds-icon-cell ds-v-scope"><i data-pix="t/hide" /><i data-pix="t/show" /></span> | `t/hide`, `t/show` | Enable a profile. Never "view" |
| Delete | <span class="ds-icon-cell ds-v-scope"><i data-pix="t/delete" /></span> | `t/delete` | Always danger, always confirmed |
| Version history | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/log" /></span> | `i/log` | Profiles |
| Create | <span class="ds-icon-cell ds-v-scope"><i data-pix="t/add" /></span> | `t/add` | New profile, New migration |
| Import, export | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/import" /><i data-pix="i/export" /></span> | `i/import`, `i/export` | Profiles |
| Search | <span class="ds-icon-cell ds-v-scope"><i data-pix="a/search" /></span> | `a/search` | The search field, as a decoration inside it |
| Filters | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/filter" /></span> | `i/filter` | The Filters button |
| Reset | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/reload" /></span> | `i/reload` | The reset of a filter panel, as an icon without text |
| Previous, next | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/previous" /><i data-pix="i/next" /></span> | `i/previous`, `i/next` | Pager arrows |
| Calendar | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/calendar" /></span> | `i/calendar` | Date fields, as a decoration |
| Clear, close | <span class="ds-icon-cell ds-v-scope"><i data-pix="e/cancel" /></span> | `e/cancel` | Clear a field, close a bar |
