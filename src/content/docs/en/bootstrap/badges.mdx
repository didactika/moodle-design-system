A badge is a short label: a count (4 messages) or a status (Completed, Hidden). It sits next to a title, a button or a row, and it is read together with it.

## When to use it

<div class="ds-do-dont">
<Rule kind="do" title="Use it">

- One or two words, or a number.
- Use pills (`rounded-pill`) for statuses and counters.
- Pick the colour by meaning and keep the same one for the same status everywhere.

</Rule>
<Rule kind="dont" title="Don't">

- Write sentences in a badge.
- Use badges as buttons.
- Use many colours in one list: it stops meaning anything.

</Rule>
</div>

## Anatomy

A `badge` with a **background colour** and text that contrasts with it. Inside a button it keeps its colour and gets a small gap.

## Combinations

| Combination | Use it for |
|---|---|
| Soft × list | Statuses in a table or a list: soft with a dot and a pill shape ("Active", "Pending review"). |
| Filled × count | Counters on buttons and icons: filled, in a pill, in danger when it asks for attention. |
| Outline × secondary | A tag that describes without alerting (a category, a version). |
| Badge + icon | An icon before the text for a status that has one (Completed with a check). Not both an icon and a dot. |
| Badge × corner | A counter on the corner of an icon button or an avatar (`badge-float` inside `position-relative`). |

## What Didactika changes and why

| What we changed | Why it helps |
|---|---|
| Soft is the default for statuses | A page full of filled badges shouts; tints let the eye read the rows and still see which one is "Pending". |
| The text colour is derived from the role | A soft badge keeps 4.5:1 whatever the colour of the theme, which a fixed pastel cannot. |
| The dot repeats the colour in a shape | The status is not only a colour: the dot plus the word says it twice. |
| Corner counters have a ring of the page colour | The count stays readable over any icon. |

## Accessibility

- A count should say what it counts: add visually hidden text ("unread messages").
- The contrast of the text against the colour is at least 4.5:1: use `text-bg-*`, which picks it.
- A status is also written, not only coloured.
