A range picks a value between a minimum and a maximum by dragging. Use it when the user compares positions (volume, opacity, a pass mark) and show the number beside it, because a slider is not precise.

## When to use it

<div class="ds-do-dont">
<Rule kind="do" title="Use it">

- Set `min`, `max` and `step` so the values make sense.
- Show the current value next to the slider.
- A label, linked with `for` and `id`.

</Rule>
<Rule kind="dont" title="Don't">

- Use it for a value the user must type exactly; use a number field.
- Use it for a few named options; use radios.
- Restyle the track or the thumb in a plugin.

</Rule>
</div>

## Anatomy

A range has a **label**, a **track** and a **thumb**. The value is not drawn by the control: write it beside it.

## Combinations

| Combination | Use it for |
|---|---|
| Range + value | Show the number next to the slider; a slider alone is not precise. |
| Range + number field | When people sometimes need the exact value, put a number field beside it. |
| Range × disabled | The thumb turns grey and the track stays, so the value is still readable. |

## What Didactika changes and why

| What we changed | Why it helps |
|---|---|
| A thin rounded track and a round thumb with a white border | The thumb stays visible on any track colour and is big enough to grab. |
| The thumb is the primary colour and grows a ring on focus | The keyboard user sees which slider has the focus and where the thumb is. |

## Accessibility

- Arrows, Home, End and Page keys work on the native element.
- The value is read by screen readers; if you also show it, mark it `aria-hidden` or link it with `aria-describedby`.
- Do not rely on dragging only: allow a keyboard path.
