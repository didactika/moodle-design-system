A progress bar shows a known amount of completion. When the amount is not known (waiting for a server), use a spinner instead.

## When to use it

<div class="ds-do-dont">
<Rule kind="do" title="Use it">

- Show the number next to the bar when the exact value matters.
- Use the success colour only for completion.
- Give it a text label that says what progresses.

</Rule>
<Rule kind="dont" title="Don't">

- Use a bar when you cannot tell how long it will take.
- Animate a bar that is not changing.
- Use it as a chart.

</Rule>
</div>

## Anatomy

A **track** (`progress`) and one or more **bars** (`progress-bar`) whose width is the value. A bar can be striped, animated and carry a label.

## Classes

| Class | What it does |
|---|---|
| `progress` | The track; its height sets the bar height |
| `progress-bar` | The filled part; width in `style` |
| `progress-bar-striped`, `progress-bar-animated` | Stripes and movement |
| `bg-success`… | Colour of a bar |

## Accessibility

- `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and an `aria-label`.
- The value is also written as text when it matters.
- Animated stripes respect the reduced motion preference.
