Una barra de progreso muestra una cantidad conocida de avance. Cuando no se conoce (esperando a un servidor), usa un indicador de carga.

## Cuándo usarlo

<div class="ds-do-dont">
<Rule kind="do" title="Úsalo">

- Mostrar el número junto a la barra cuando importa el valor exacto.
- Usar el color de éxito solo para lo completado.
- Darle una etiqueta de texto que diga qué progresa.

</Rule>
<Rule kind="dont" title="No">

- Usar una barra cuando no se sabe cuánto va a tardar.
- Animar una barra que no cambia.
- Usarla como gráfico.

</Rule>
</div>

## Anatomía

Un **riel** (`progress`) y una o más **barras** (`progress-bar`) cuyo ancho es el valor. Una barra puede ir a rayas, animada y con una etiqueta.

## Clases

| Clase | Qué hace |
|---|---|
| `progress` | El riel; su altura marca la de la barra |
| `progress-bar` | La parte rellena; ancho en `style` |
| `progress-bar-striped`, `progress-bar-animated` | Rayas y movimiento |
| `bg-success`… | Color de una barra |

## Accesibilidad

- `role="progressbar"` con `aria-valuenow`, `aria-valuemin`, `aria-valuemax` y un `aria-label`.
- El valor también se escribe como texto cuando importa.
- Las rayas animadas respetan la preferencia de movimiento reducido.
