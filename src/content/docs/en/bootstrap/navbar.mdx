A navbar holds the main navigation of a site. It shows the brand, the places people go most, and the tools of the account, and folds into a menu button when the screen is narrow.

## When to use it

<div class="ds-do-dont">
<Rule kind="do" title="Use it">

- Five to seven main links, the current one marked.
- The brand on the left, the tools (search, account) on the right.
- Put the less used links inside a dropdown.
- Let it collapse below the breakpoint that fits the number of links.

</Rule>
<Rule kind="dont" title="Don't">

- Fill it with every page of the site.
- Use two navbars one above the other.
- Change the order of the links between pages.

</Rule>
</div>

## Anatomy

A **brand** (`navbar-brand`), a **toggler** for small screens (`navbar-toggler`), a collapsible area (`navbar-collapse`) with the **links** (`navbar-nav`, `nav-link`) and optional **forms** or text (`navbar-text`).

## Variants and states

### Moodle's navigation bar

The bar of Moodle is the one every user knows, and each version draws it its own way: Moodle 5.3 with the pill and the dot of its design system, Moodle 4.x with the underlined link. The bar below is what Moodle renders in the selected version; a plugin does not draw its own.

## Combinations

| Combination | Use it for |
|---|---|
| Brand × links × tools | Brand on the left, the main links next to it, the tools (search, notifications, account) on the right. |
| Links × dropdown | The less used links go inside a dropdown ("More") so the bar never wraps. |
| Light × primary | A light bar for working screens, a bar in the primary colour for a tool with its own identity. |
| Icons × badges | Tool icons with a counter on the corner (`badge-float`); the account as initials or a photo. |

## What Didactika changes and why

| What we changed | Why it helps |
|---|---|
| Moodle's bar keeps its design in each version | The user must find the same navigation in every course; the design system documents it, it does not replace it. |
| Links are pills with a tint, the current one is stronger | It is clear where you are from the weight and the tint, not only from the colour. |
| A thin border and rounded corners on the standalone navbar | It separates the bar from the page without a heavy shadow. |

## Classes

| Class | What it does |
|---|---|
| `navbar`, `navbar-expand-lg` | The bar, and the width from which it expands |
| `navbar-brand` | Brand |
| `navbar-nav`, `nav-link` | The links; `active`, `disabled` |

## In this version

<Only of="v53">

Bootstrap 5.3 keeps its colours in CSS variables (`--bs-*`), so a theme recolours the component with one variable. The bar sits in a `container-fluid` and the dark bar is set with `data-bs-theme="dark"`.

</Only>

<Only of="v45">

Bootstrap 4.6 compiles its colours into the classes, so a theme recolours the component by rebuilding its stylesheet. The light and dark bars are `navbar-light` and `navbar-dark`, and the search form is `form-inline`.

## Accessibility

- Wrap it in a `nav` (the navbar already is one) and give it an `aria-label` if the page has more than one.
- The toggler has `aria-controls`, `aria-expanded` and `aria-label`.
- The current page has `aria-current="page"`.
- Everything is reachable with the keyboard in the visual order.
