Un plugin nunca escribe una clase de Font Awesome. Pide a Moodle un icono por su identificador (`t/edit`, `i/reload`), con `{{#pix}}t/edit, core{{/pix}}` en una plantilla o `$OUTPUT->pix_icon('t/edit', ...)` en PHP, y el código React usa los mismos identificadores. Moodle asocia cada identificador a un icono de su Font Awesome, y un tema puede asociarlo a otro.

<Only of="v41" inline>Esta versión dibuja los iconos con Font Awesome 4.7.</Only><Only of="v45,v53" inline>Esta versión dibuja los iconos con Font Awesome 6.</Only>

## Un significado por icono

| Significado | Icono | Id de Moodle | Uso |
|---|---|---|---|
| Editar, o abrir un elemento que aún puede cambiar | <span class="ds-icon-cell ds-v-scope"><i data-pix="t/edit" /></span> | `t/edit` | Perfiles, migraciones en revisión |
| Abrir el detalle de un elemento que ya no puede cambiar | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/info" /></span> | `i/info` | Migraciones completadas |
| Mostrar u ocultar, activar o desactivar | <span class="ds-icon-cell ds-v-scope"><i data-pix="t/hide" /><i data-pix="t/show" /></span> | `t/hide`, `t/show` | Activar un perfil. Nunca "ver" |
| Eliminar | <span class="ds-icon-cell ds-v-scope"><i data-pix="t/delete" /></span> | `t/delete` | Siempre peligro, siempre con confirmación |
| Historial de versiones | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/log" /></span> | `i/log` | Perfiles |
| Crear | <span class="ds-icon-cell ds-v-scope"><i data-pix="t/add" /></span> | `t/add` | Nuevo perfil, Nueva migración |
| Importar, exportar | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/import" /><i data-pix="i/export" /></span> | `i/import`, `i/export` | Perfiles |
| Buscar | <span class="ds-icon-cell ds-v-scope"><i data-pix="a/search" /></span> | `a/search` | El campo de búsqueda, como decoración dentro de él |
| Filtros | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/filter" /></span> | `i/filter` | El botón Filtros |
| Restablecer | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/reload" /></span> | `i/reload` | El restablecer de un panel de filtros, como icono sin texto |
| Anterior, siguiente | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/previous" /><i data-pix="i/next" /></span> | `i/previous`, `i/next` | Flechas del paginador |
| Calendario | <span class="ds-icon-cell ds-v-scope"><i data-pix="i/calendar" /></span> | `i/calendar` | Campos de fecha, como decoración |
| Borrar, cerrar | <span class="ds-icon-cell ds-v-scope"><i data-pix="e/cancel" /></span> | `e/cancel` | Borrar un campo, cerrar una barra |
