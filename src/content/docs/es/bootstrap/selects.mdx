Un selector deja elegir una opción (o varias) de una lista corta y conocida. Es el selector propio del tema: comportamiento nativo, con la altura, el borde y la flecha de los demás campos.

## Cuándo usarlo

<div class="ds-do-dont">
<Rule kind="do" title="Úsalo">

- Un selector para de 4 a unas 15 opciones que el usuario ya conoce.
- Una etiqueta visible, enlazada con `for` e `id`.
- Una primera opción que diga qué hacer ("Elige…") cuando no hay un valor por defecto.
- `multiple` con `size` solo cuando el usuario debe ver las opciones a la vez.
- Moodle ajusta un selector a su contenido; añade `w-100` donde deba llenar la fila.

</Rule>
<Rule kind="dont" title="No">

- Usar un selector para dos opciones; usa [radios](../checks/) o un interruptor.
- Usarlo para una lista larga o con búsqueda; el autocompletado de Moodle es el componente para eso.
- Dar estilo a las opciones; las dibuja el navegador.
- Cambiar la flecha o la altura en un plugin.

</Rule>
</div>

## Anatomía

Un selector tiene una **etiqueta**, el **control** con la opción elegida y una **flecha**, y la **lista** que abre el navegador. Las mismas reglas de pista y mensaje que un [campo de texto](../form-controls/).

### La lista que se abre

El navegador dibuja por su cuenta la lista de un selector y una página no puede darle estilo. En este sistema un selector abre en su lugar un menú del sistema de diseño: el mismo que tiene un desplegable, con los grupos como encabezados, las opciones desactivadas atenuadas y la elegida marcada. El selector conserva su valor y sus eventos, así que el marcado de un plugin no cambia. Pruébalo también con el teclado (flechas, Inicio, Fin, una letra, Intro, Escape).

### Tamaños

<Example title="Pequeño, normal y grande" src="selects/sizes" measure="Height,Padding,Font size,Line height,Radius,Border" />

Usa el tamaño normal. El pequeño es para sitios densos (una barra de filtros sobre una tabla, las filas por página de un paginador); el grande, solo para un campo principal único de una página.

## Varios valores como etiquetas

Un select con el atributo `multiple` se dibuja como un campo de etiquetas: lo elegido se muestra como piezas que se quitan una a una, y las opciones se abren en el menú del sistema de diseño, con una marca, que sigue abierto mientras la persona elige. El select de debajo conserva sus valores y sus eventos, así que el marcado de un plugin no cambia. El mismo campo admite también texto libre (etiquetas que aún no existen); mira la página "Etiquetas".

## Combinaciones

| Combinación | Para qué usarla |
|---|---|
| Selector × pocas opciones | De 4 a unas 15 opciones que el usuario ya conoce. Menos de 4: radios. Más de 15, o con búsqueda: el autocompletado de Moodle. |
| Selector + optgroup | Agrupa las opciones con `optgroup`; el menú muestra cada grupo como un encabezado. |
| Selector + grupo de entrada | Un selector pegado a un botón («Ocultar | Aplicar»): el grupo los une en un solo control. |
| Ancho | Moodle ajusta un selector a su contenido. Añade `w-100` donde deba llenar la fila. |

## Qué cambia Didactika y por qué

| Qué cambiamos | Por qué ayuda |
|---|---|
| La lista que se abre es un menú del sistema de diseño | La lista nativa no se puede estilar, así que cada navegador mostraba una lista distinta y simple que no encajaba con el resto de la página. Un menú se ve igual en todas partes y muestra la opción elegida. |
| La flecha tiene su propio espacio a la derecha | Las opciones largas nunca pasan por debajo de la flecha, en ningún tamaño. |
| Misma altura, borde y foco que un campo de texto | Un selector junto a un campo parece su hermano, no otro componente. |

## En esta versión

<Only of="v53">

Bootstrap 5.3 dibuja el foco como un anillo suave y guarda cada color en variables CSS (`--bs-*`), así que un tema recolorea un control con una sola variable. La flecha es una imagen de fondo que el tema puede cambiar.

</Only>

<Only of="v45">

</Only>

## Accesibilidad

- Una etiqueta en cada selector.
- No uses `onchange` para navegar o enviar; da un botón.
- El comportamiento nativo del teclado (flechas, escribir para buscar) es gratis: conserva el elemento nativo.
- Un mensaje de error se enlaza con `aria-describedby`.
