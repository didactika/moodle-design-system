A button starts an action. It is the same component in every plugin: the one of the theme, with its own classes, never redrawn by a plugin. Only the chrome of a list (the toolbar over a table) rounds its buttons, and it does so with a layer class, not by restyling `.btn`.

## When to use it

<div class="ds-do-dont">
<Rule kind="do" title="Use it">

- `btn-primary` for the main action of a page, a form or a dialog. One per area.
- `btn-secondary` or `btn-outline-secondary` for the others: Cancel, Import, Export.
- `btn-danger` for what deletes or stops, also on the confirm button of its dialog.
- An icon before the text when the action has one in the [icon table](../../foundations/icons/); an icon-only button always has a title and a hidden label.

</Rule>
<Rule kind="dont" title="Don't">

- Redraw buttons in a plugin: colours, radius, padding or weight.
- Put two primary buttons side by side.
- Use a link styled as a button to submit a form, or a button to navigate.
- Use red for anything that does not remove or stop.

</Rule>
</div>

## Anatomy

A button has a **label** (text, or an icon with a hidden label), an optional **icon** before the label, and a **colour** that says what it does. There is no trailing icon.

## Variants and states

Every colour against every state. Hover, focus and pressed are forced from the version's own CSS, so what you see is what a user sees.

Use the default size almost everywhere. Small belongs in dense places (a floating bar, a row of a table); large only for a call to action on an empty page.

## Classes

| Class | What it does |
|---|---|
| `btn` | Base of every button |
| `btn-primary`, `btn-secondary`, `btn-success`, `btn-danger`, `btn-warning`, `btn-info`, `btn-light`, `btn-dark` | Colour by meaning |
| `btn-outline-*` | Outlined variant for secondary actions |
| `btn-link` | Looks like a link, acts like a button |
| `btn-sm`, `btn-lg` | Smaller and larger |
| `btn-group` | Joins related buttons |
| <Only of="v53" inline>`d-grid gap-2`</Only><Only of="v45,v41" inline>`btn-block`</Only> | Full-width stack |
| <Only of="v53" inline>`btn-close`</Only><Only of="v45,v41" inline>`close`</Only> | Close button inside alerts and modals, written by Moodle |

## Accessibility

- A `button` for an action and an `a` for navigation; never the other way round.
- An icon-only button has `title` and `aria-label` (or a hidden text).
- `disabled` removes it from the tab order; use `aria-disabled` only when the reason must stay readable by keyboard users.
- Pressed state of a toggle: `aria-pressed`.
- Contrast of the label against the colour meets 4.5:1 in every theme colour of Moodle; a theme that changes the colours has to keep that.
