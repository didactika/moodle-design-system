A spinner tells the user that the system is working. Use it for waits of unknown length: loading a list, saving, sending. For a known amount, use a progress bar.

## When to use it

<div class="ds-do-dont">
<Rule kind="do" title="Use it">

- Say what is loading with a text, visible or hidden.
- Use the small size inside a button and disable the button.
- Show it only after a moment (about 300 ms), so quick loads do not flash.

</Rule>
<Rule kind="dont" title="Don't">

- Cover the whole page when only a part is loading.
- Leave it spinning after an error: show the error.
- Use two spinners at once for the same wait.

</Rule>
</div>

## Anatomy

A circle that turns (`spinner-border`) or pulses (`spinner-grow`) with a **hidden label** for assistive technology.

## Accessibility

- `role="status"` and a hidden label ("Loading…").
- Inside a button, the spinner is `aria-hidden` and the button text says what happens.
- Under reduced motion the spinner turns slower, never stops.
